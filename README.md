# B Personal Website / B PRSNL Webby

A futuristic, recruiter- and client-facing personal website for Balla Cisse: Full-Stack Software Engineer and Data & Intelligent Systems Engineering Specialist.

## Stack

- Next.js + React + TypeScript
- Tailwind CSS
- Framer Motion-ready architecture
- Local typed content files under `src/data`

## Current implementation

This iteration establishes the project foundation, global visual system, animated background, hero section, resume-derived sections, portfolio cards, certifications, awards, and contact CTA.

## Run locally

```bash
npm install
npm run dev
```
## Development standards

This project includes architecture hardlocks to prevent design drift during future iterations. Review `docs/architecture-hardlocks.md` before adding sections, animation systems, major visual treatments, or new content models.
